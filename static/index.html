如何获取高德 Web服务 Key 与 Google Maps Key？（点此展开）

1. 高德开放平台（国内精确定位 + 实时地铁换乘）：登录 lbs.amap.com → 控制台「应用管理 → 我的应用」→ 创建新应用 → 点击「添加 Key」，服务平台务必勾选 「Web服务」（不要选 Web端 JS API），复制生成的 32 位 Key 填入下方即可。

2. Google Maps Platform（港澳台及海外地点 + 实时路况）：打开 console.cloud.google.com → API 和服务 → 启用 Places API (New)、Geocoding API 与 Distance Matrix API（或 Routes API） → 在「凭据」中创建 API 密钥填入下方。

3. 双引擎自动分流：两个都填好后保持「自动选择」，国内地址自动走高德，海外/英文地址自动走 Google Maps。
